# Space Marine Mod

Warhammer 40K Space Marine armor and weapons for Minecraft 1.21.4

## Features

- Complete Space Marine armor set (helmet, chestplate, leggings, boots)
- Boltgun weapon with custom bolt ammunition
- Jetpack dash ability

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/space-marine-mod/releases).
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- Equip the Space Marine armor set for enhanced protection.
- Use the Boltgun weapon to shoot bolts.
- Activate the jetpack dash ability by pressing the assigned key.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
